A program that writes one funny single-line one-star review — a house cat reviewing its human, under 200 characters — to `/output/entry.txt`.

> One star. He calls the warm keyboard his 'office'. I have slept on it since 2019. He is the squatter.

## Run it

```sh
python3 main.py
```

It writes the review to `/output/entry.txt` and prints the same line to stdout.
